# AI SummarySage ✨📝

What if your notes wrote themselves? Turn walls of text into “aha!” moments with a tap. AI SummarySage uses Google’s Gemini to shape ideas into summaries that feel tailor-made — formal, funny, poetic, and everything in between.

## Why You’ll Love It

- 🎯 Summaries in your style:
  - Formal for reports
  - Casual for quick reads
  - Bullet Points for crisp clarity
  - Funny for fun brain fuel
  - Poetic for vibes
  - Gen-Z for max sauce
- 🎤 Speak it: Record audio, get instant transcriptions
- 📁 Drop files: PDF, DOC/DOCX, or TXT — just upload
- 🔊 Hear it: Text-to-speech for on-the-go listening
- 💬 Share fast: One-tap WhatsApp sharing
- 🌓 Feel right: Dark mode that respects your focus

## Quickstart

1) Clone the repo
```bash
git clone https://github.com/Ank0it/AI-SummarySage.git
cd AI-SummarySage
```
2) Install dependencies
```bash
npm install
```
3) Run the development server
```bash
npm run dev
```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

# AI Summary Sage 📝

**AI Summary Sage** is a web-based text summarization tool powered by a **Large Language Model (LLM) API**. It helps users quickly extract key insights from long documents by generating concise, context-aware summaries. The platform also includes a one-tap **WhatsApp sharing** feature for easy distribution of summaries.

---

## 🌟 Key Features

- **LLM-Powered Summarization:** Uses a large language model API to generate accurate and context-aware summaries.  
- **User-Friendly Interface:** Simple and intuitive web interface for easy usage.  
- **One-Tap Sharing:** Share summaries instantly via WhatsApp.  
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.  
- **FastAPI Backend:** Handles requests efficiently and communicates with the LLM API.

---

## 🛠 Technologies Used

- **Python** – FastAPI backend, LLM API integration  
- **HTML, CSS, JavaScript** – Frontend interface  
- **Render** – Backend deployment
