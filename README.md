# AI Summary Sage 📝

**AI Summary Sage** is a web-based text summarization tool powered by a **Large Language Model (LLM) API**. It helps users quickly extract key insights from long documents by generating concise, context-aware summaries. The platform also includes a one-tap **WhatsApp sharing** feature for easy distribution of summaries.

---

## 🌟 Key Features

- **LLM-Powered Summarization:** Uses a large language model API to generate accurate and context-aware summaries.  
- **User-Friendly Interface:** Simple and intuitive web interface for easy usage.  
- **One-Tap Sharing:** Share summaries instantly via WhatsApp.  
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.  
- **FastAPI Backend:** Handles requests efficiently and communicates with the LLM API.

---

## 🛠 Technologies Used

- **Python** – FastAPI backend, LLM API integration  
- **HTML, CSS, JavaScript** – Frontend interface  
- **Render** – Backend deployment
